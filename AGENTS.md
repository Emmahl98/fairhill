# Fairhill deployment requirements

- Keep the public maintenance screen with the exact heading `Working on this site!` on every update until the owner explicitly requests its removal.
- Preserve password-gated preview access. The owner's preview password is not stored in this public repository; obtain it from the authorized conversation or owner when rebuilding.
- Do not commit the unencrypted preview content or the password into this public repository while the development gate is active.
- Never publish submissions from the private Google Sheet.
- Target GitHub Pages and custom domain `fairhill-civ.com`.
